# Earlier command examples

The IOS, Linux and PowerShell files in this directory belong to the first build. They are learning references, not captured exports of the current six-VLAN environment.

The current design has trunks from R1 Ethernet0/0 to SW1 and R1 Ethernet0/2 to SW2. It uses VLANs 10/20/30 and 40/50/60. Do not combine these facts with the earlier physical-interface LAN 30 example as if both were the same running configuration.

Start with the [current architecture](../docs/architecture.md) and [validation checklist](../docs/test-plan.md). Actual device configuration should be exported from the lab before replacing these examples with a full reproducible configuration.
